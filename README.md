# Retina AI - AI-Powered Retinal Disease Screening & Tele-Ophthalmology

A comprehensive AI-assisted tele-ophthalmology platform developed for Smart India Hackathon (SIH26038). The platform streamlines rural & point-of-care retinal screenings for conditions such as Diabetic Retinopathy, Glaucoma, Age-Related Macular Degeneration (AMD), and Hypertensive Retinopathy.

---

## 🌟 Key Features

- **Multi-Role Workspaces**:
  - **Nurse / Field Worker**: Rapid patient registration, point-of-care image acquisition, instant AI triage scoring, offline queue & cloud sync management.
  - **Doctor / Ophthalmologist**: AI-assisted case review workspace, multi-class severity classification, lesion heatmaps / Grad-CAM visual explanations, automated clinical report generator with digital sign-off.
  - **Tele-Ophthalmology**: Real-time teleconsultation, patient triage scheduling, referral routing.
  - **Patient Portal**: Bilingual clinical summary, visual timeline of retinal health, lifestyle/diet recommendations, emergency alerts.
  - **Population Health & Analytics**: Epidemiological prevalence heatmaps, screening turnaround analytics, referral compliance metrics.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **State Management**: React Context API
- **Build Tool**: Vite 6

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
`ash
# Clone the repository
git clone https://github.com/Harshinig-123/SIH26038.git

# Navigate to project directory
cd SIH26038

# Install dependencies
npm install

# Run the development server
npm run dev
`

### Build for Production
`ash
npm run build
npm run preview
`
